# Lumen-Reach
AI made game of a cozy life sim. I'm open sourcing this so others can play with the idea of this game. I'm not expecting much from it. This was 100% made by AI. 
__________
The prompt used was:

Make me a life sim game. One where I can live through a character I make. One where  I can enable real world problems like autism, depression, etc. Realistic conversations I can interact with and I can talk to others and they will interact with what I say. I can use the keyboard. It needs to have meaning in everything there. Meaning like food shouldn't magically fill someone up, but they should aim to sit and eat at a table like a normal person. Make it is a futuristic theme with robots. Magic like stuff is explained with nanobots. Meaning there is "magic" but it is highly grounded and limited. 

There needs to be a full economy, UBI but an ability to make more money, most stuff is automated but likely a desire for some human made stuff or just a human might make something AI wouldn't simply like 1 person might make something another wouldn't not that it can't. 

It's based on real physics. There should be some space society part of it and then you have time mechanics. 

Basically it is a futuristic cozy game. realistic looking as possible.
_____________

A huge reason why I made this is to test where we are at and where the limits are. This is where we are as of 2026.
